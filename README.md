# 段永平投资判断 · 价值投资方法论

把《大道：段永平投资问答录》蒸馏成可执行的 **投资判断方法论** 的 AI Skill——不是原文检索，而是把书中的方法论内化为编码习惯。

### 15 秒速览
- **这是什么**：一个「价值投资判断框架」Skill——把段永平 20 年投资问答，提炼成 AI 能直接套用的决策规则与红线。
- **给谁用**：散户、价值投资者、理财自媒体——想在买入前想清楚「懂不懂、好不好、贵不贵、该不该碰」的人。
- **解决什么痛点**：原书 500+ 页问答散落各处；本 Skill 把「买股票就是买公司、不懂不碰、不做空不借钱」浓缩成 R1–R6 决策卡，AI 一键帮你逐条排查。
- **边界**：提供判断框架，不构成投资建议；不荐股、不预测短期涨跌。

## 核心立场

> 买股票就是买公司；只在懂的生意上、以便宜/合理价格、长期下注；其余不碰。

## 它帮你做什么

当用户问"XX 股票/公司值得投吗""这笔投资该不该做""段永平会怎么看 XX"，本 Skill 加载后按段永平的决策框架逐条套：

- **R1 懂不懂** → 不懂直接否决（不做空、不借钱、不懂不碰）
- **R2 生意质量** → 商业模式 > 便宜；好公司、好文化优先
- **R3 价格** → 现金流折现毛估估，留安全边际
- **R4 市场情绪** → 利用市场先生，而非跟随
- **R5 持有/卖出** → 长期主义 + 触发条件

## 包含内容

- 决策规则 R1–R6
- 不为清单（红线）
- 模板 T1–T3（标的快速筛查卡、买卖小桌、假懂三问）
- 心智模型（所有者思维、长期主义、本分、平常心）
- 真实案例模式（苹果 / 茅台 / 腾讯 / 网易 / 步步高）+ 段永平做人/创业总纲

## 边界声明

本 Skill 提供**判断框架**，不构成投资建议；不预测短期涨跌、不荐股，只帮用户把"懂不懂、好不好、贵不贵、该不该碰"想清楚。涉及真金白银请自行决策、自担风险。
